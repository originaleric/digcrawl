# 2026-07-03 · 今日头条文章抓取稳定性修复同步

## 背景

本轮目标是让今日头条“文章”抓取达到生产可用状态，并明确排除视频/西瓜落点。此前真实样本测试暴露了三类问题：

- collect/runtime 默认 60 秒外层 timeout 会先于浏览器链路取消，导致慢文章失败。
- 头条 API 探测经常返回 HTML/风控壳页，既不能成功解析，又会增加固定延迟。
- 部分 `toutiao.com/group/...` 实际跳转到 `ixigua.com`，不属于文章范围，却会拖到浏览器超时。

## 本次改动

### 1. collect runtime timeout 对齐

- `collect.RunOptions` 新增 `TimeoutMs`。
- `collect.Service` 根据 `LocalBrowser.TotalTimeoutSec + 30s` 设置 runtime 外层预算。
- 避免平台浏览器链路仍在正常工作时被 collect 默认 timeout 提前打断。

### 2. Browser fetch 结果解析增强

- `PageFetchResult` 增加 `ContentType`。
- 页面内 `fetch` 返回统一 JSON 字符串，兼容 Rod `ObjectToJSON` 返回字符串字面量的情况。
- 头条 API 路径可以记录 `api_content_type`、`api_response_type`、`api_body_prefix`，方便诊断非 JSON/HTML/风控响应。

### 3. 头条 API 快速降级

- 头条 API 探测总预算限制为 4 秒。
- 非 JSON、HTML、空响应、登录/验证提示会被分类为 API fallback，而不是误判成解析失败。
- Browser fallback 仍保留为主兜底路径。

### 4. 文章范围与内容质量校验

- 新增头条 preflight：短超时跟随重定向并识别 `ixigua.com`、抖音、短视频、`/video/`、`awemevideo` 等非文章落点。
- 新增 `CONTENT_TYPE_MISMATCH` 结构化错误码，并纳入 fatal error。
- Browser 结果返回后继续校验壳页标题、空正文和视频 marker，避免导出占位内容。

### 5. JSON text 完整性与 selector 性能

- metadata `text` 只有在比现有正文更完整时才覆盖。
- 当 Markdown 明显比 Text 更完整时，从 Markdown 派生纯文本反补 JSON `text`。
- 头条 selector fallback 改为组合 selector 优先，跨站文章样本从约 87 秒降到约 6 秒。
