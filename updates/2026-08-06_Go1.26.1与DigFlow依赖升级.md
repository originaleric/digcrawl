# 2026-08-06 Go 1.26.1 与 DigFlow 依赖升级

## 本次更新

- 将仓库 Go 基线从 `1.24.8` 升级为 `1.26.1`。
- 将 DigFlow 从 `v1.1.3` 升级为 `v1.1.4`，并移除会强制解析旧版 `v1.1.3` 的 module replace 声明。
- 将 GoDig 从 `v1.0.4` 升级为 `v1.0.8`。
- 随 DigFlow 升级收敛必要的传递依赖，包括 DigEino、Eino OpenAI / DeepSeek provider 与 JSON Schema 依赖。
- Release 工作流同步改用 Go `1.26.1`。

## 兼容性

- DigFlow `v1.1.4` 的模块基线同为 Go `1.26.1`，无需额外业务代码迁移。
- DigCrawl 现有内嵌路径使用的 `pkg/digflow.NewRuntime`、`Invoke` 与 `Stream` 接口保持兼容。
- GoDig 在本仓库中仅为间接依赖，未发现直接 import，因此不需要调用侧改造。
- DigFlow `v1.1.4` 本次不要求 SQL DDL 迁移。

## 验证

- `go mod verify`
- `go test ./cmd/digcrawl ./internal/summary ./config`
- `go test -tags digflow_embedded ./internal/summary`
- 默认模式与 `digflow_embedded` 模式的 `digcrawl` 均已成功构建，并通过 `--help` 冒烟验证。

## 本机提示

若 shell 环境仍导出旧版 `GOROOT`，需要先执行 `gvm use go1.26.1`，或显式设置 `GOROOT=/Users/dig/.gvm/gos/go1.26.1` 后再调用 Go 1.26.1 二进制，避免混用旧标准库。
