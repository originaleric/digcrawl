# 2026-08-20 Skill 媒体下载与 ASR 错误链优化

## 本次更新

- Skill 媒体单文件默认上限由 10 MiB 提升为 128 MiB，默认下载超时调整为 120 秒；新建 profile、示例 profile 与当前本机 Skill profile 使用同一默认值。
- 新增 `Skill.Media.MaxASRCandidates`，默认值为 `2`：先尝试主音视频，再尝试一个回退候选。候选下载、转写、磁盘占用与外层调用时间不再随页面媒体数量无界增长。
- Runtime 与 MCP 使用相同的候选预算计算调用 deadline；显式 ASR 或视频摘要不会在第二个候选下载/转写时被外层 context 提前取消。
- ASR 输入下载失败现在在 Skill 边界直接返回结构化 `MEDIA_DOWNLOAD_FAILED`，包含媒体类型、失败原因、是否可重试及必要的大小信息；不会将签名 URL 等原始下载错误泄露给调用方，也不会再让用户从 ASR 报错倒查下载问题。
- 对 `include_ocr + include_asr` 组合请求，OCR 仅采集图片，ASR 始终走同一有限候选循环；两部分结果合并写入同一媒体 manifest，避免组合开关绕过候选上限。

## 行为说明

- 只要没有任何本地音视频可供转写，调用会直接返回媒体下载错误；若已获取本地媒体但转写失败，则返回 ASR 错误，保留正确的故障归属。
- 默认两次候选会相应增加最坏情况的调用 deadline，但成功路径会立即返回。若业务更偏向快速失败，可在 profile 中设定 `MaxASRCandidates: 1`。
