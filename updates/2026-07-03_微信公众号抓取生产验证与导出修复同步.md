# 2026-07-03 · 微信公众号抓取生产验证与导出修复同步

## 更新摘要

本轮围绕微信公众号公开文章抓取完成闭环：

- 微信公众号读取改为 HTTP HTML 静态解析优先，Browser 只作为 transient/不确定场景兜底。
- 增加微信域名 scope invariant，HTTP redirect、HTTP final URL、Browser final URL 任一跳出微信允许域名均返回 `SCOPE_VIOLATION`。
- 平台读取成功后统一校验真实标题和正文，避免把微信壳页、风控页或占位页作为正常文章导出。
- 修复 `--format md,json,html` 归一化，JSON/Markdown/HTML 输出不再互相误删内容字段。
- 修复 collect 导出长中文标题按字节截断导致的 macOS `illegal byte sequence`，改为 UTF-8 边界截断并清理非法字节。
