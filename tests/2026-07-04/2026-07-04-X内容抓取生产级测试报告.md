## 关键过程

### Round 1

样本：用户提供的疑似 X 帖子 URL。

结果：采集命令返回成功，但实际内容是 X 壳页，正文包含“page doesn’t exist/Search”。同时官方 Tweet lookup API 返回 `402`。

Finding：

- Browser fallback 会把 X 不存在/不可见壳页误判为成功。
- 当前 X API 凭据没有 Tweet lookup 读取权限或对应套餐能力，返回 `402 Payment Required`。

修复：

- 增加 X Browser 内容校验，登录壳、不可见壳、删除/不存在壳不再写成成功结果。
- 将 Tweet lookup `402` 标记为权限/套餐不足诊断，并允许继续尝试公开 oEmbed fallback。

### Round 2

样本：公开稳定帖子 `jack/status/20`。

结果：Browser 无登录态被 X 登录墙拦截，不能作为稳定主路径。

修复：

- 增加官方公开 `publish.twitter.com/oembed` 端点作为 API fallback。
- oEmbed 成功时映射正文、作者、发布时间、HTML、canonical URL，并写入 `read_channel=api`、`extraction_source=oembed`。
- oEmbed 的 404/403/429 在 JSON 解码前结构化返回，避免无意义 Browser 等待。

### Final Round

```bash
GOCACHE=/private/tmp/digcrawl-gocache go run ./cmd/digcrawl collect --config config/config.yaml --file tests/2026-07-04/x-prod-round-4-urls.txt --format md,json --out tests/2026-07-04/x-prod-final
```
