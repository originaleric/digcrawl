# 2026-07-04 第1轮 GLM-OCR 生产级测试报告

## 结论

第1轮未作为最终质量结论采用。原因是 3 个 Wikipedia/Commons 缩略图样本在生产路径中不可稳定访问：

- DigCrawl 本地下载路径返回 `http 403`。
- 智谱远程 `layout_parsing` 调用等待超时。

智谱公开文档截图样本通过，说明 provider 与 API key 可用；但 Wikipedia 样本无法有效评价 OCR 识别质量，因此第2轮更换为可下载、可远程访问的公网图片重新测试。
