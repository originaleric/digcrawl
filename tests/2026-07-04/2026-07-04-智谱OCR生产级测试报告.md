## 配置建议

当前可以直接用以下配置把智谱视觉 OCR 接入 DigCrawl：

```yaml
OCR:
  Enabled: true
  Provider: openai_compatible
  APIKey: "<zhipu-api-key>"
  BaseURL: "https://open.bigmodel.cn/api/paas/v4"
  Model: "glm-5v-turbo"
  Prompt: "Extract all readable text from this image. Return only the OCR text."
  TimeoutSec: 60
  MaxImages: 8
  MaxImageBytes: 8388608
  MaxTokens: 1200
  AppendToMarkdown: true
  AppendToText: false
```

如果后续希望使用智谱专门的 `glm-ocr` 或 `files/ocr` 原生接口，建议新增 `Provider=zhipu_ocr`，由 provider 内部适配 `layout_parsing` / `files/ocr` 的请求和响应格式；这不是本轮测试的阻塞项。

## 剩余风险

- 当前 DigCrawl 已验证的是智谱 OpenAI-compatible 视觉接口路径，不是智谱 `layout_parsing` 原生 provider。
- 测试样本为官方公开图片 URL，尚未覆盖私有图片、超大图片、批量多图和 provider 限流场景。
- `glm-5v-turbo` 属于视觉理解模型，虽然能完成 OCR 抽取，但文档/表格版面还原能力应以 `glm-ocr` 原生接口为准。
