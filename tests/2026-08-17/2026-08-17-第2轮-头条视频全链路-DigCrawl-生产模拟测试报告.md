## 2. 本轮修复的生产前阻塞项

此前的本地 ASR 配置路径名为 `digcrawl-asr-venv`，但其 Python 实际指向 Homebrew 系统解释器，`sys.prefix` 与 `sys.base_prefix` 相同，并非虚拟环境；其中也未安装 `faster_whisper`。历史报告只验证了 ASR 失败语义，未完成真实 ASR 成功验收。

本轮完成以下修复：

1. 创建隔离的 Python 3.12 ASR venv，并安装 `faster-whisper` 及运行依赖；最终部署在用户持久 DigCrawl 数据目录，不使用会被系统清理的临时目录。
2. 将本机 Skill ASR 配置切换到该持久 venv。
3. 为 `scripts/faster_whisper_asr.py` 新增无网络 `--check` 模式，确认模块可以导入。
4. 将 `digcrawl doctor` 的本地 ASR 检查从“命令文件存在”提升为：对内置 faster-whisper runner 实际执行 `--check`。

`doctor --config <skill-profile>` 的 binary、profile、artifact directory、browser、ffmpeg、ASR provider 与 MCP startup 共七项均通过。
