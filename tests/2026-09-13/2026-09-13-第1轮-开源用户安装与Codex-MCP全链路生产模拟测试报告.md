## 6. Findings

已修复一个产品缺陷：安装器此前只安装二进制，不负责创建 Skill profile 或注册/修复 Codex MCP；因此历史上写入临时构建路径的 `mcp_servers.digcrawl` 会在临时目录被清理后失效。现在安装器会将该条目原子替换为刚安装的稳定二进制，并保留其它 Codex 设置和 MCP server。公开 GitHub 安装入口返回 404 仍是仓库尚未公开、尚未发布 Release 的预期状态；不影响修复的预发布验证。
