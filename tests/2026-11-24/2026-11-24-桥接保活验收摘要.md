# 2026-11-24 桥接保活验收摘要

本次发布范围为 DigCrawl 自身的稳定运行目录、串行维护、可选 macOS watcher 与完整 MCP 附件交付；不增加动态迁移或第三方应用改造。

- 本机 macOS arm64 的 11 套原生验收通过：Shell/npm 安装更新、不同程序与在途截图更新、停止、重启、取消等待、发布前后失败、EOF/TERM、恢复重试、相对目录归属、浏览器数据保留、socket 恢复、维护互斥及停机回退。
- 真实 MCP 截图在 stop/restart/install/cancel/update 中完整交付，附件不再依赖任务后的第二次 RPC；多附件、空数据、大响应、部分错误、缺失和超限场景由自动化回归覆盖。
- 相关 Go 包无缓存 race、静态检查及格式检查通过；原生测试进程和 LaunchAgent 已收尾。原始日志、程序、浏览器副本与测试配置保留本地。
- 普通 CI 保持手动 workflow_dispatch。本次按用户明确要求执行 Linux、macOS、Windows 三平台 CI；精确提交与结果以 GitHub Actions 为准，不用交叉构建代替运行验收。
- 发布下载在原生测试中使用本地构建和 SHA 校验 fixture；发布后另核对公开安装包与 npm 安装入口。

旧版无完整排空能力时先等待任务结束并用旧版停止；强杀整个维护进程树、断电及宿主连接自动迁移不在通过范围。公开操作说明见 ../../docs/本地Bridge保活与迁移.md。
