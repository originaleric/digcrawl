# 2026-10-10 第3轮浏览器 Findings 修复与系统复核

本轮接续上一轮只读 review 的四项 P2。此前报告中的“无新增 findings”是当时的结论；本报告补充此前遗漏的 API-first、截图、Reddit 输出及外部 target 清理边界。

## 修复等级与系统约束

等级 C。单人单机，继续由现有 browserManager 管理 opening/active/retiring/stopCh、槽位和租约，由已有 browseRetryState 管理调用内时间、重试及诊断。未新增恢复服务、target 注册表、持久化状态或新的抽象/领域。

本轮保持三条不变量：一次平台读取的 API-first 与 DOM fallback 共用浏览器 deadline 和最多一次故障重试；浏览器故障保持结构化错误直到 Runtime；连接释放和页面释放分别验证，外部服务不能被应用的恢复路径终止。业务 API 响应失败仍可走有限回落；POST 发出后不自动重放。

入口覆盖 PageFetchJSON、BrowserBrowse、平台 API-first 客户端、截图回落、Reddit provider、BrowserSnapshot、BrowserAction、doctor CheckOperation，以及普通/立即关停和迟到会话释放。

## 四项 Findings 与结果

1. **API-first 绕过预算、重试和错误规则：已修复。** 将现有重试状态的 deadline、attempt、retry claim 和退避收拢为原类型的方法，BrowserBrowse 与 PageFetchJSON 共用。PageFetch acquire/navigation/load/CDP 错误保留 BrowseError；正常 HTTP/API 失败保留业务回落。抖音、小红书与头条策略不再将浏览器基础设施错误转成 API fallback。头条遇到这类错误停止端点轮询；已经判定为 fatal 的 HTTP/API 响应也立即终止，不再被后续端点结果覆盖。成功输出携带诊断，公共 provider 的 ReadError 输出也保留浏览器尝试诊断。
2. **小红书截图无条件掩盖读取失败：已修复。** 只在 CanBrowseFallback 允许且未取消时回落；清除失效的 wait selector；截图没有恢复正文则保留读取失败；恢复正文标记 PARTIAL_CONTENT；截图自身基础设施失败直接上抛。登录/验证码等终止信号不被部分内容标记覆盖。
3. **Reddit 丢失错误原因和诊断：已修复。** provider 建立外层共享调用标记，成功及后处理失败输出携带诊断；RSS 失败不再把 BrowseError 转成无 cause 的 ReadError，Runtime 继续输出 operation、diagnostic_id、next_actions 等字段。
4. **外部 CDP 断连被当作 target 清理成功：已修复。** 已知页面 Page.Close 失败后，以独立时限执行 Target.closeTarget；只有关闭成功或查询确认该 ID 不存在才接受释放，并清理 Rod 缓存状态。未知 target 或无法证明关闭时，在原连接上记录未释放错误，保留 retiring/stopErr 屏障，不自动连接同一服务继续创建页面。提示清理/重启外部浏览器，再重启 DigCrawl。立即关停仅能强制清零自有浏览器租约，外部连接仍等待已有 target 租约释放。

关闭失败回传覆盖所有会话使用者。POST 即使已经返回成功，也不会因后续页面清理失败被重放；有副作用的 BrowserAction 清理失败明确标为不可重放。doctor 不再把未能清理的测试页面报告为成功。

## 系统级复核记录

复核沿调用边界检查错误/计数和 deadline，又沿资源边界检查创建、关闭、退役、关停和迟到释放。连带修复了外部立即关停清零租约、force close 缓存状态、截图覆盖登录状态、头条 fatal 响应后继续端点探测、doctor 关闭错误及成功 POST 清理失败后的重放问题。没有引入第二套所有权或恢复机制。

残余边界：外部 target 身份未知时，本机无法安全推断哪个页面归本次调用所有，也不能关闭整个外部进程。采用隔离并提供人工操作指引；清理外部浏览器后需要新的 Bridge 进程解除保守隔离。平台真实登录/验证码和实时 API 变化未逐个实测，相关策略由已有业务信号处理。本轮新增平台流程的验证以故障注入为主。

最终全仓库回归、Race 和 Windows 交叉编译均通过。系统级复核未发现剩余可执行的 P0/P1/P2 findings。外部未知 target 的人工清理要求与 Windows 实机验证边界如上保留，未声称可自动推断或已完成实机验证。
